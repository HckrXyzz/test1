# Project Structure

Complete project folder and file organization:

```
│── index.html

├── css/
│   ├── style.css
│   ├── hacker.css
│   ├── animation.css

├── js/
│   ├── app.js
│   ├── ui.js
│   ├── loader.js
│   ├── parser.js
│   ├── filter.js
│   ├── search.js
│   ├── table.js
│   ├── duplicate.js
│   ├── statistics.js
│   ├── charts.js
│   ├── export.js
│   ├── image.js
│   ├── theme.js
│   ├── notification.js
│   ├── storage.js
│   └── helper.js
```

## File Descriptions

### CSS Files
- **style.css** - Main stylesheet with base styles
- **hacker.css** - Hacker theme styles  
- **animation.css** - Animation definitions

### JavaScript Modules
- **app.js** - Main application initialization
- **ui.js** - UI management and rendering
- **loader.js** - Data loading from external sources
- **parser.js** - Data parsing (JSON, CSV, etc.)
- **filter.js** - Data filtering utilities
- **search.js** - Search functionality
- **table.js** - Table rendering
- **duplicate.js** - Duplicate detection
- **statistics.js** - Statistical calculations
- **charts.js** - Chart generation
- **export.js** - Export data functionality
- **image.js** - Image handling and processing
- **theme.js** - Theme management
- **notification.js** - User notifications
- **storage.js** - Local storage management
- **helper.js** - Helper utilities and functions
